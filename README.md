# To-Do App

## About:
A simple ToDo application made using Kotlin with Gradle. It utilizes data and enum classes,
mutable lists, exception handling and in-built functions. Users can add, remove, complete
and filter tasks. The program has an execution timer and a count for completed, deleted and
active tasks. All information is output to the console.

## Unit testing:
The application is organized into src/main/kotlin for the main application code and
src/test/kotlin for unit testing. The unit tests verify the code functionality via testing various
scenarios with task status, task adding, removal and filtering.
